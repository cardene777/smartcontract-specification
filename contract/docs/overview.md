# Avalanche Stablecoin システム概要

このドキュメントは、Avalanche Stablecoinスマートコントラクトシステムの全体像を説明します。

## プロジェクト概要

Avalanche Stablecoinは、Avalancheブロックチェーン上で動作するステーブルコインシステムです。

## 主要機能

- **トークン発行・償却**: 承認されたユーザーによるステーブルコインの発行と償却
- **送金管理**: ユーザー間のトークン送金とバンク機能
- **アクセス制御**: マルチシグとロールベースの権限管理
- **アップグレード可能性**: プロキシパターンによるコントラクトのアップグレード対応

## アーキテクチャ

詳細は[アーキテクチャページ](./architecture.md)を参照してください。

## コントラクト一覧

システムは以下のコントラクトで構成されています：

- **Core Contracts**: システムの中核となるコントラクト
- **Features**: 機能モジュール（発行、送金、管理等）
- **Access Control**: 権限管理とマルチシグ
- **Libraries**: 共通ライブラリ

詳細は各コントラクトのドキュメントを参照してください。
