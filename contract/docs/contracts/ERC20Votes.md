## 🔧 主要機能

### 関数一覧

| 名前 | 説明 |
|------|------|
| numCheckpoints | 指定されたアカウントのチェックポイント数を取得します。<br /><br />チェックポイントは、投票権の変更履歴を記録するデータ構造です。<br />各委任や転送により新しいチェックポイントが作成されます。<br /> |
| checkpoints | 指定されたアカウントの指定された位置のチェックポイントを取得します。<br /><br />チェックポイントには、特定時点での投票権とブロック番号が含まれます。<br /> |
| error_ERC20ExceededSafeSupply | 総供給量の上限を超えた時に返されるエラーです。<br /><br />ERC20Votesでは、チェックポイントをTrace208構造体に格納するため、総供給量がtype(uint208).max(2^208 - 1)を超えることができません。<br />この制限を超えてmintしようとした場合に発生します。<br /><br />**パラメータ:**<br />- `increasedSupply` (uint256): 増加後の総供給量<br />- `cap` (uint256): 最大供給量の上限<br /> |
