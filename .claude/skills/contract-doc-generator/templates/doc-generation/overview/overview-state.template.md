# 状態管理

このページでは、Avalanche Stablecoinシステムにおける状態管理について説明します。

## ストレージ構造

システムの状態は、以下の要素で構成されています：

- **ユーザー残高**: 各ユーザーのトークン残高
- **バンク口座**: バンク機能における口座情報
- **権限情報**: ユーザーのロールと権限
- **設定情報**: システム全体の設定パラメータ

## 状態遷移

詳細な状態遷移については、各コントラクトのドキュメントを参照してください。

## アップグレード時の状態保持

プロキシパターンにより、アップグレード時も状態が保持されます。
